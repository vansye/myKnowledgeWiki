## 背景

Java Swing 基础实践项目，通过经典的贪吃蛇游戏掌握 GUI 编程、键盘事件处理、多线程和持久化存储。

## 功能

- **三种游戏模式**：Normal（标准）、Hard（快速）、Crazy（速度递增）
- **排行榜系统**：每种模式独立前 10 名，数据持久化到 rankings.dat
- **技能系统**：加速冲刺 + 金身护体
- **多食物机制**：场上同时存在 5 个食物
- **键盘控制**：WASD 或方向键

## 技术要点

- Java Swing 绘制游戏画面
- Thread 实现游戏主循环
- Serializable / FileReader 实现排行榜持久化
- 贪吃蛇经典碰撞检测算法
