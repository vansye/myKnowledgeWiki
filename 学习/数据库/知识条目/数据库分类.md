## 详细

### 概念
数据库是用于存储、管理和检索数据的系统。根据数据组织方式、存储结构和应用场景，可划分为多种类型。主流的分类方式是将其分为关系型数据库（SQL）和非关系型数据库（NoSQL）。

### 重点

#### 一、关系型数据库（SQL）
采用二维表结构组织数据，通过 SQL 查询语言操作，强调 ACID 事务特性。

| 代表产品 | 特点 | 适用场景 |
| :--- | :--- | :--- |
| MySQL / MariaDB | 开源主流，社区活跃 | Web 应用、中小型系统 |
| PostgreSQL | 功能丰富，扩展性强 | 复杂查询、地理信息 |
| Oracle | 商业闭源，性能强大 | 大型企业、金融系统 |
| SQL Server | 微软生态深度集成 | .NET 技术栈 |

#### 二、非关系型数据库（NoSQL）
灵活的数据模型，多用于大规模数据和高并发场景。

| 类型 | 代表产品 | 数据模型 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **键值存储** | Redis、Memcached | Key-Value | 缓存、会话存储、计数器 |
| **文档存储** | MongoDB、Elasticsearch | JSON / BSON 文档 | 内容管理、日志、电商商品 |
| **列族存储** | HBase、Cassandra | 列簇宽表 | 大数据分析、时序数据 |
| **图数据库** | Neo4j、JanusGraph | 节点+边+属性 | 社交关系、推荐引擎、知识图谱 |

#### 三、其他分类维度
| 维度 | 分类 |
| :--- | :--- |
| 部署形态 | 本地部署（On-Premise）、云数据库（RDS、云原生） |
| 处理模式 | OLTP（事务型）、OLAP（分析型）、HTAP（混合型） |
| 存储介质 | 磁盘存储、内存存储（如 Redis） |
| 数据时效 | 持久化数据库、流式数据库（如 Kafka） |

#### 四、选型建议
- **业务核心数据**（用户、订单、财务）→ 关系型数据库
- **高并发缓存 / 会话** → 键值存储（Redis）
- **灵活数据模型 / 快速迭代** → 文档存储（MongoDB）
- **海量日志 / 分析** → 列族存储（HBase）或 Elasticsearch
- **关系推理 / 社交网络** → 图数据库（Neo4j）
