## 详细

### 概念
Vue 是一套用于构建用户界面的渐进式 JavaScript 框架。它的核心库只关注视图层，采用 MVVM 设计模式，通过响应式数据驱动视图自动更新。

### 重点
- **响应式**：数据变化时视图自动更新，Vue 3 基于 Proxy 实现
- **组件化**：页面由一个个可复用的组件构成
- **组合式 API**：Vue 3 推荐的代码组织方式，逻辑按功能聚合
- **生态**：Vite（构建工具）+ Pinia（状态管理）已成主流
- **生命周期**：组件从创建到销毁经历挂载、更新、卸载等阶段
