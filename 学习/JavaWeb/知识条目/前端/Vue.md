## 详细

### 概念
Vue 是一套用于构建用户界面的渐进式 JavaScript 框架。它的核心库只关注视图层，采用 MVVM 设计模式，通过响应式数据驱动视图自动更新。

### 重点
- **响应式**：数据变化时视图自动更新，Vue 3 基于 Proxy 实现，详见 [[响应式对象]]
- **组件化**：页面由一个个可复用的组件构成
- **组合式 API**：Vue 3 推荐的代码组织方式，详见 [[API风格]]
- **模板语法**：插值 `{{ }}` 和指令 `v-*`，详见 [[Vue 模板]]
- **工程化**：从脚手架到部署的完整流程，详见 [[Vue工程化]]
