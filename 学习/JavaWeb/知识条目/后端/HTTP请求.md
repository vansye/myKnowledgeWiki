## 详细
### 概念

HTTP 请求是浏览器或客户端发给服务器的消息，通常包含请求行、请求头、请求体三部分。初学 JavaWeb 时，需要先理解请求方法、请求路径和请求参数分别表示什么。常见方法有 GET、POST、PUT、DELETE。


### 重点

- GET 常用于查询，参数常出现在 URL 上
- POST 常用于提交表单或上传数据
- 请求头里可以携带 Host、Cookie、Content-Type 等信息
