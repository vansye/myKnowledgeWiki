## 详细

### 概念

RESTful 规范是一种设计 Web 接口的风格，强调用 URL 表示资源，用 HTTP 方法表示操作。初学 JavaWeb 时，它经常出现在接口设计、接口命名和前后端联调中。


### 重点

- URL 通常表示资源，而不是动作
- GET、POST、PUT、DELETE 分别对应查询、创建、更新、删除操作
- 接口返回值一般会尽量保持统一格式
