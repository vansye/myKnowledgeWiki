## 详细

### 概念

HTTP 响应是服务器返回给客户端的结果，通常包含状态行、响应头和响应体。它决定了浏览器最终看到什么内容，以及这次请求是否成功。状态码是初学者最先需要记住的部分。HTTP 响应与 [[HTTP请求]] 成对出现，[[Servlet]] 负责生成并返回 HTTP 响应。


### 重点

- 200 表示成功，404 表示资源不存在，500 表示服务器内部错误
- 响应头会说明内容类型、编码、缓存等信息
- 响应体是浏览器最终展示或下载的内容
