## 详细

### 概念

Servlet 是运行在 [[Tomcat]] 等 Web 容器中的 Java 类，专门负责处理客户端的 [[HTTP请求]] 并生成 [[HTTP响应]]。它的生命周期由容器管理，开发者通常只需要关注业务处理逻辑。Servlet 是理解 Java Web 请求处理流程的基础。


### 重点

- 依赖容器创建、初始化、调用和销毁
- 常用于理解请求分发、参数获取、响应输出
- 是学习 Java Web 原理时最基础的入口之一
