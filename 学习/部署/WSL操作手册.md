## 1. 基础管理与日常使用

### 1.1 查看 WSL 状态及发行版信息

在 Windows PowerShell 或命令提示符中执行以下命令：

| 命令 | 说明 |
|------|------|
| `wsl -l -v` | 列出所有已安装的发行版，并显示其运行状态和 WSL 版本（1 或 2） |
| `wsl --status` | 查看 WSL 的全局状态，包括默认发行版、默认 WSL 版本、内核版本等 |
| `wsl --list --running` | 仅列出当前正在运行的发行版 |
| `wsl --help` | 显示 WSL 所有可用命令及参数 |

### 1.2 启动、进入与退出

- **进入默认发行版终端**：直接执行 `wsl`
- **进入指定发行版**：`wsl -d <发行版名称>`（例如 `wsl -d Ubuntu-22.04`）
- **在 Windows 中执行 Linux 命令**：`wsl <命令>`，例如 `wsl ls -la`，会执行并返回结果，不进入交互式 shell
- **退出 Linux 终端**：在终端内输入 `exit` 或按 `Ctrl+D`

### 1.3 停止与重启发行版

| 命令 | 说明 |
|------|------|
| `wsl -t <发行版>` | 优雅地停止指定的发行版（相当于关机） |
| `wsl --shutdown` | **立即停止所有**正在运行的 WSL 发行版（包括 WSL 2 虚拟机） |
| `wsl --terminate <发行版>` | 与 `-t` 相同，强制终止 |

> **注意**：停止发行版后，下次进入时会重新启动，启动速度较快（WSL 2 为轻量级虚拟机）。
