## 详细

### 概念
Linux 发行版是一个基于 Linux 内核，并集成了 GNU 工具链、桌面环境、应用软件及包管理系统的完整操作系统。

### 重点
- **两大主流体系**：
  - **Debian 系**：使用 `.deb` 包和 `APT` 包管理器。代表：Debian、Ubuntu、Linux Mint。
  - **Red Hat 系**：使用 `.rpm` 包和 `YUM/DNF` 包管理器。代表：RHEL、Fedora、CentOS。
- **其他体系**：Arch Linux（使用 `pacman`，滚动更新）。
- **主流发行版特点**：
  - **Ubuntu**：新手友好，适合桌面和服务器。
  - **Debian**：极其稳定，适合服务器。
  - **RHEL**：企业级标准，付费商业支持。
  - **Fedora**：技术前沿，适合开发者。
  - **CentOS**：已停止维护，替代品为 AlmaLinux、Rocky Linux。
